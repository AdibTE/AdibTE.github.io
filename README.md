# Adib M. Rohani — Portfolio

Personal portfolio (EN / FA), built with TanStack Start and deployed to GitHub Pages.

## Scripts

```bash
npm install
npm run dev          # local development
npm run build:pages  # static build for GitHub Pages
npm run preview      # preview production build
```

## Deploy

Push to `master`. GitHub Actions builds and publishes to:

https://adibte.github.io/portfolio-lovable/
